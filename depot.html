const fs = require('fs'); const path = require('path'); const express = require('express'); const crypto = require('crypto'); const db = require('../db'); const { auth, authLimiter, byCode, normalizePhone } = require('./auth'); const router = express.Router(); const MIN = Number(process.env.DEPOSIT_MIN || 1000); const MAX = Number(process.env.DEPOSIT_MAX || 1000000); const PRESETS = [3000, 5000, 10000, 20000, 40000, 100000, 200000, 500000].filter((v) => v >= MIN && v <= MAX); const ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789'; // Les comptes de réception : variables du .env OU fichier payments.json (jamais écrits dans le code) function fileCfg() { try { return JSON.parse(fs.readFileSync(path.join(__dirname, '..', 'payments.json'), 'utf8')); } catch { return {}; } } const clean = (v) => (typeof v === 'string' ? v.trim() : ''); function methods() { const f = fileCfg(); const out = []; const wave = { number: clean(process.env.PAY_WAVE_NUMBER) || clean(f.wave && f.wave.number), name: clean(process.env.PAY_WAVE_NAME) || clean(f.wave && f.wave.name) }; const om = { number: clean(process.env.PAY_ORANGE_NUMBER) || clean(f.orange && f.orange.number), name: clean(process.env.PAY_ORANGE_NAME) || clean(f.orange && f.orange.name) }; if (wave.number) out.push({ id: 'wave', label: 'Wave', ...wave }); if (om.number) out.push({ id: 'orange', label: 'Orange Money', ...om }); return out; } console.log('Dépôts ouverts avec : ' + (methods().map((m) => m.label).join(', ') || 'aucun moyen configuré (voir payments.json)')); const newRef = () => { let s = 'DEP'; for (let i = 0; i < 8; i++) s += ALPHABET[crypto.randomInt(ALPHABET.length)]; return s; }; const qExpire = db.prepare("UPDATE deposits SET status = 'expired', updated_at = datetime('now') WHERE user_id = ? AND status = 'pending' AND expires_at <= datetime('now')"); const qPending = db.prepare("SELECT COUNT(*) AS n FROM deposits WHERE user_id = ? AND status = 'pending'"); const qInsert = db.prepare("INSERT INTO deposits (user_id, reference, amount, method, payer_phone, expires_at) VALUES (?, ?, ?, ?, ?, datetime('now', '+15 minutes'))"); const qGet = db.prepare("SELECT *, CAST(strftime('%s', expires_at) - strftime('%s', 'now') AS INTEGER) AS seconds_left FROM deposits WHERE id = ? AND user_id = ?"); const qSetTx = db.prepare("UPDATE deposits SET tx_id = ?, status = 'submitted', updated_at = datetime('now') WHERE id = ? AND user_id = ? AND status = 'pending'"); function view(d) { const m = methods().find((x) => x.id === d.method); const open = d.status === 'pending' || d.status === 'submitted'; return { id: d.id, reference: d.reference, amount: d.amount, method: d.method, method_label: m ? m.label : d.method, payer_phone: d.payer_phone, status: d.status, seconds_left: d.status === 'pending' ? Math.max(0, d.seconds_left) : 0, tx_id: d.tx_id, confirmed_amount: d.status === 'confirmed' ? d.amount : 0, pay_to: open && m ? { number: m.number, name: m.name } : null }; } router.get('/deposit-config', auth, (req, res) => { res.json({ min: MIN, max: MAX, presets: PRESETS, methods: methods().map(({ id, label }) => ({ id, label })) }); }); router.post('/deposits', authLimiter, auth, (req, res) => { const b = req.body || {}; const avail = methods(); if (!avail.length) return res.status(503).json({ error: "Les dépôts ne sont pas encore ouverts. Réessaie bientôt." }); const amount = Number(b.amount); if (!Number.isInteger(amount) || amount < MIN || amount > MAX) { return res.status(400).json({ error: 'Le montant doit être entre ' + MIN + ' et ' + MAX + ' FCFA.' }); } const m = avail.find((x) => x.id === b.method); if (!m) return res.status(400).json({ error: 'Choisis un moyen de paiement.' }); const country = byCode[req.user.country]; const payer = country ? normalizePhone(country, b.payer_phone) : null; if (!payer) return res.status(400).json({ error: 'Numéro de paiement invalide.' }); qExpire.run(req.user.id); if (qPending.get(req.user.id).n >= 3) { return res.status(429).json({ error: 'Tu as déjà plusieurs dépôts en attente. Termine-les ou attends leur expiration.' }); } let id = null; for (let i = 0; i < 5 && !id; i++) { try { id = qInsert.run(req.user.id, newRef(), amount, m.id, payer).lastInsertRowid; } catch (e) { if (e.code !== 'SQLITE_CONSTRAINT_UNIQUE') throw e; } } if (!id) return res.status(500).json({ error: 'Impossible de créer le dépôt. Réessaie.' }); res.status(201).json({ deposit: view(qGet.get(id, req.user.id)) }); }); router.get('/deposits/:id(\\d+)', auth, (req, res) => { qExpire.run(req.user.id); const d = qGet.get(Number(req.params.id), req.user.id); if (!d) return res.status(404).json({ error: 'Dépôt introuvable.' }); res.json({ deposit: view(d) }); }); // Le membre envoie l'identifiant de sa transaction : cela NE crédite PAS le solde. router.post('/deposits/:id(\\d+)/transaction', authLimiter, auth, (req, res) => { qExpire.run(req.user.id); const d = qGet.get(Number(req.params.id), req.user.id); if (!d) return res.status(404).json({ error: 'Dépôt introuvable.' }); if (d.status !== 'pending') return res.status(400).json({ error: 'Ce dépôt ne peut plus recevoir d’identifiant.' }); const tx = typeof (req.body || {}).tx_id === 'string' ? req.body.tx_id.trim() : ''; if (!/^[A-Za-z0-9_-]{6,40}$/.test(tx)) { return res.status(400).json({ error: 'Identifiant de transaction invalide (6 à 40 lettres, chiffres, - ou _).' }); } try { qSetTx.run(tx, d.id, req.user.id); } catch (e) { if (e.code === 'SQLITE_CONSTRAINT_UNIQUE') return res.status(409).json({ error: 'Cet identifiant de transaction a déjà été utilisé.' }); throw e; } res.json({ deposit: view(qGet.get(d.id, req.user.id)) }); }); module.exports = { router };
